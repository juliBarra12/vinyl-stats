# Vinyl Stats 🎧
Vinyl Stats is a personal project for automatically tracking vinyl listening sessions and exploring listening habits though data.

## Idea 💡

The goal is to build a system capabale of identifying the record being played, logging listening sessions, and using that data to generate statistics about my vinyl listening habits.

Eventually, the project may combine a software application with a small hasdware device connected to the turntable setup.
